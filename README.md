PU Pulse 🍔⚡Campus-Scale Rapid Food Delivery & Real-Time Logistics System for Parul UniversityPU Pulse is a high-performance web platform designed specifically for university campuses to streamline, accelerate, and digitize food ordering and delivery across multiple campus canteens, food courts, and student hostels. Inspired by modern quick-commerce platforms like Blinkit, PU Pulse delivers an intuitive, fast-loading ordering experience backed by real-time sync.   💡 Overview & Problem StatementUniversity campuses present unique food delivery challenges: high peak-time order volumes, dense multi-building hostel structures, strict class schedules, and inefficient manual queues.PU Pulse solves this by offering:Instant Campus Delivery: Rapid routing designed for university building layouts and hostel blocks.   Real-Time Order Tracking: Seamless updates from canteen kitchen preparation to final doorstep/gate delivery.   Lightweight Architecture: High responsiveness even on low-bandwidth campus Wi-Fi or cellular networks.   ✨ Key Features🍔 Interactive Digital Canteen Menu: Browse live food inventory, daily specials, and custom combos across Parul University dining spots.   ⚡ AI-Powered Order Suggestions: Smart recommendations built with Google AI Studio to customize food combos based on dietary preferences and student budgets.   🔄 Real-Time Database Sync: Powered by Firebase Firestore for real-time order status tracking (Received ➔ Preparing ➔ Out for Delivery ➔ Delivered).   📱 Responsive Mobile-First Design: Smooth, app-like web interface optimized for instant mobile ordering.   📍 Campus Geolocation & Building Select: Pre-mapped hostel gates, academic blocks, and campus hotspots for swift delivery handoffs.   🛠️ Tech Stack & ToolsFrontend: HTML5, CSS3 (Custom Glassmorphism Utilities), Modern JavaScript (ES6+)   AI & Prototyping: Google AI Studio (Gemini-driven menu intelligence & UX copy generation)   Backend & Database: Firebase Firestore & Firebase Realtime Database   Deployment & Hosting: GitHub Pages / Firebase Hosting
